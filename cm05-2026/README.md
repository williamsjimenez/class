# CM05 · Laboratorio de Diseño Metodológico (2026)

Aplicación publicada desde el repositorio GitHub existente `williamsjimenez/class`, sin alterar sus materiales anteriores.

**Portal previsto:** https://williamsjimenez.github.io/class/cm05-2026/

**Curso:** CM05, Seminario de Investigación. **Tarea 5:** 1.500 palabras, entrega 15 de noviembre de 2026; diseño metodológico (50%), contactos de expertos (25%), guion de entrevistas (25%). Los temas de los 16 grupos vienen de la matriz del curso, y las preguntas se completan por los estudiantes.

## Uso

Seleccionar grupo; recorrer los 10 pasos del diseño; elegir categorías preestablecidas o agregar otras; justificar cada decisión; añadir expertos y preguntas; descargar borrador Markdown o copia JSON privada. El progreso queda únicamente en el navegador que se utiliza.

## Gestión de grupos

En **Editar grupos**, se pueden modificar los temas e integrantes y crear nuevos grupos. El profesor puede importar el archivo `CM05_2026_integrantes_PRIVADO_importar.json` desde su equipo. Ese documento se entrega al profesor **fuera del repositorio público**, no debe subirse aquí. La exportación pública elimina el campo `integrantes`.

## Lo que falta para uso síncrono entre estudiantes

Esta versión es una aplicación estática, sin autenticación, base de datos ni guardado remoto. **No registra ni transmite respuestas entre equipos.** Para obtener un tablero docente con respuestas en tiempo real es necesario conectar un servicio con autenticación y políticas de acceso por grupo (por ejemplo Supabase) y establecer un canal privado para las entregas. No introducir datos personales de expertos en repositorios públicos.

Para verificar la publicación, consultar el flujo **Pages build and deployment** del repositorio.
